# الكريمي — تصور مستقل لتجربة مصرفية

أضيف المشروع المحلي `kuraimi_app` إلى قسم التطبيقات ومسار `/projects/kuraimi/`، مع الحفاظ على ترتيب المشاريع السابقة. تتولّى منظومة البناء الحالية توليد صفحة HTML وبيانات SEO للمشروع تلقائيًا.

## نطاق المشروع

المصدر المرجعي هو `kuraimi_app/README.md` و`pubspec.yaml` وملفات `lib/`. المشروع نموذج Flutter شخصي وغير رسمي، بواجهات عربية وبيانات وهمية ومحاكاة محلية. لا يتصل بخوادم البنك ولا ينفّذ معاملات مالية فعلية. البصمة عبر `local_auth` تفتح النموذج المحلي؛ NFC وQR محاكاة. لا ينبغي تقديمه باعتباره تطبيق البنك الرسمي أو منتجًا مصرفيًا منشورًا.

## المعاينة المستقلة

تفتح روابط المعاينة في بطاقة المشروع وصفحة تفاصيله المسار `/showcase/kuraimi/index.html`، مع canonical إلى `/showcase/kuraimi/` في البناء المنشور. هذه صفحة HTML مستقلة من `public/showcase/kuraimi/index.html`، وتحافظ على تصميم معرض `kuraimi_app/design_preview/index.html` البنفسجي والذهبي وأقسامه الثمانية ولقطاته الـ39 ومؤشر الشعار المتحرك. لا تستخدم غلاف React أو تنقّل صفحة الأعمال، وتتضمن رابطين للعودة إلى دراسة المشروع وقسم الأعمال.

حُذف زر تنزيل APK وروابط صفحات الأدوات والمصادر المحلية من المعاينة. يوضح تقديم الصفحة أنها نموذج شخصي غير رسمي ببيانات محلية تجريبية، دون اتصال بخوادم البنك أو تنفيذ عمليات مالية. لا يتضمن الموقع APK أو Flutter Web أو فيديو أو مجلد بناء التطبيق.

تُعاد الاستفادة من اللقطات الست في الجدول أعلاه عبر مسارات نسبية `../../projects/kuraimi/`. اللقطات الثلاث والثلاثون الأخرى موجودة في `public/showcase/kuraimi/images/`؛ تحمل أسماء المصادر نفسها في `kuraimi_app/design_preview/` مع استبدال امتداد `.png` بـ`.webp`. حُوّلت إلى 640×1428 بجودة 82، ومجموعها 983,700 بايت. جميع اللقطات مؤجلة التحميل باستثناء لقطة تسجيل الدخول الأولى. تستخدم روابط التكبير الصور المضغوطة نفسها وتفتحها في تبويب جديد.

مصدر `brand-mark.webp` هو `assets/branding/kuraimi-mark.png`، ويُنسخ `logo-loading.svg` من المعاينة الأصلية مع احترام تقليل الحركة. تظل الروابط نسبية لتعمل الصفحة من جذر الموقع ومن مسار GitHub Pages الفرعي.

يحتوي المصدر على بيانات SEO احتياطية للمعاينة المحلية بين العلامتين `<!--showcase-seo-start-->` و`<!--showcase-seo-end-->`. يستبدل البناء هذا الجزء ببيانات المسار الفعلية، بما يشمل canonical وسياسة الفهرسة وOpen Graph وTwitter وCreativeWork JSON-LD، وفق إعدادات بيئة النشر.

يحافظ المعرض على خط Cairo الأصلي من `assets/fonts/Cairo-Variable.ttf` بحجم 599,548 بايت، مع `font-display: swap` ونسخة ترخيصه `fonts/OFL.txt`. تعذّر توفير محوّل الخط بسبب مهلة تنزيل الاعتماد، فحُفظ الخط الأصلي محليًا لضمان تطابق العرض دون اعتماد خارجي.

إجمالي الملفات المضافة للمعاينة المستقلة: 38 ملفًا بحجم 1,633,868 بايت (نحو 1.56 MiB). هذا الإجمالي لا يكرر الصور الست المشتركة مع دراسة المشروع، ولا يتضمن ملفات APK أو فيديو أو مكتبات تشغيل Flutter.
